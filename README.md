
# Обнаружение транспортных средств перед шлагбаумом с использованием YOLOv3 и OpenCV

## 1. Описание проекта

Проект представляет собой систему автоматического обнаружения транспортных средств перед шлагбаумом на основе методов компьютерного зрения и глубокого обучения.

Для распознавания объектов используется предварительно обученная нейросетевая модель **YOLOv3**, интегрированная с библиотекой **OpenCV**.

Система обрабатывает видеопоток из файла, обнаруживает автомобили и мотоциклы, анализирует заданную область интереса (ROI) и формирует визуальное и звуковое оповещение при появлении транспортного средства.

## 2. Основные возможности

- Автоматическое обнаружение автомобилей и мотоциклов на видео.
- Использование предварительно обученной модели YOLOv3.
- Анализ заданной области интереса (Region of Interest, ROI).
- Визуальное выделение обнаруженных транспортных средств.
- Отображение подписей к обнаруженным объектам.
- Звуковое оповещение при обнаружении транспорта.
- Обработка последовательности кадров видео.
- Сохранение обработанного видео в файл `result.avi`.

**Примечание:** звуковое оповещение воспроизводится во время работы программы и не включается в сохранённый видеофайл.

## 3. Принцип работы системы

Обработка видео выполняется в несколько этапов.

**1. Загрузка видео**

Программа получает на вход видеофайл, содержащий дорожную сцену перед шлагбаумом.

**2. Обнаружение объектов**

Каждый обрабатываемый кадр анализируется с помощью YOLOv3 для обнаружения объектов, включая автомобили (`car`) и мотоциклы (`motorcycle`).

**3. Анализ области интереса**

Для определения присутствия транспортного средства перед шлагбаумом используется заданная область интереса — ROI.

**4. Визуализация результатов**

При обнаружении транспортного средства отображаются зелёная ограничивающая рамка и подпись объекта.

**5. Звуковое оповещение**

При выполнении условий обнаружения программа воспроизводит звуковой сигнал.

**6. Сохранение результата**

Обработанные кадры могут сохраняться в видеофайл `result.avi` для последующего просмотра.

## 4. Используемые технологии

| Технология | Назначение |
|---|---|
| Python | Основной язык программирования |
| YOLOv3 | Обнаружение объектов на изображениях и видеокадрах |
| OpenCV | Чтение, обработка и визуализация видео |
| NumPy | Работа с массивами и числовыми данными |
| Pillow | Отображение текста, включая русскоязычные подписи |
| Pygame / winsound | Воспроизведение звукового оповещения |
| FFmpeg | Дополнительная обработка видео и звука при необходимости |

## 5. Структура проекта

Основной файл проекта:

- `код.py` — реализация обнаружения транспортных средств, обработки видео и оповещения.

Файл зависимостей:

- `requirements.txt` — список необходимых Python-библиотек.

Дополнительные файлы, необходимые для работы системы:

- `yolov3.cfg` — конфигурация архитектуры YOLOv3.
- `yolov3.weights` — предварительно обученные веса модели.
- `coco.names` — список классов объектов.
- `alert.wav` — пользовательский звуковой сигнал (необязательный файл).

**Важно:** файлы конфигурации, весов модели и списка классов YOLOv3 необходимо подготовить отдельно, если они отсутствуют в локальном каталоге проекта.

## 6. Установка и запуск

### 6.1. Подготовка окружения

Для работы необходимы Python и установленные зависимости проекта.

Клонирование репозитория:

```bash
git clone https://github.com/donette243/Detection-of-vehicles-in-front-of-the-barrier.git
```

Переход в каталог проекта:

```bash
cd Detection-of-vehicles-in-front-of-the-barrier
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

### 6.2. Подготовка файлов модели

Перед запуском необходимо подготовить:

- `yolov3.cfg`
- `yolov3.weights`
- `coco.names`
- Видеофайл для обработки

Пути к этим файлам должны соответствовать настройкам в исходном коде.

### 6.3. Запуск программы

После подготовки необходимых файлов и настройки путей выполните:

```bash
python код.py
```

Программа обрабатывает видео, отображает результаты обнаружения и формирует звуковое оповещение при выполнении заданных условий.

## 7. Звуковое оповещение

Система предусматривает два варианта воспроизведения сигнала:

- При наличии файла `alert.wav` используется пользовательский звуковой сигнал.
- При отсутствии файла используется системный сигнал `Beep`.

Звуковое оповещение работает во время выполнения программы.

Сохранённое видео `result.avi` содержит визуальные результаты обработки без звуковой дорожки.
