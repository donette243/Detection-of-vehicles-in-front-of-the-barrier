
## Обнаружение транспорта перед шлагбаумом (YOLOv3)

Программа выполняет в реальном времени детекцию автомобилей и мотоциклов, находящихся перед шлагбаумом, на основе видеофайла.

## Детекция транспорта

- На вход подаётся видеофайл
- Используется модель YOLOv3 для детекции объектов
- Анализируется зона ROI (Region of Interest) перед шлагбаумом
- Если транспорт (car, motorcycle) появляется:
- Отображается зелёная рамка и подпись
- Проигрывается звуковой сигнал (если включен)

Сохранённая версия видео ('result.avi') не содержит звук.  

Сигнал срабатывает только во время работы системы.

##  Используемые технологии

- OpenCV (обработка видео и нейросетей)
- YOLOv3 (предобученная модель)
- Pillow (для вывода текста на русском)
- Pygame / winsound (для воспроизведения звукового сигнала)
- FFmpeg (опционально — для добавления звука в итоговое видео)

##  Структура проекта

1. код.py # основной скрипт
2. yolov3.cfg # конфигурация YOLOv3
3. yolov3.weights # веса модели YOLOv3
4. coco.names # список классов
5. requirements # Список зависимостей (библиотек), которые нужно установить
6. alert.wav # звук сигнала (опционально)


##  Как использовать

1. Убедитесь, что все 'yolov3.cfg', 'yolov3.weights', 'coco.names' и видеофайл находятся в одной папке.
2. Установите зависимости:

bash

pip install -r requirements.txt

## О звуке

- Если в папке есть 'alert.wav', он воспроизводится при обнаружении.
- Если файла нет, используется системный сигнал (Beep).
